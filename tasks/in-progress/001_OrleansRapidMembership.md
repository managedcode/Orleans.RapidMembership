# Automatic in-memory Orleans membership

## Approved contract

Discover peers automatically on localhost and reachable IPv4 networks. Optional CIDR/range probes supplement multicast/broadcast. No seed IP list, advertised address or membership directory is required. All membership, incarnation, ballot and handoff state stays in RAM. Orleans owns actual silo lifecycle and grain execution. Preserve the upstream RAPID source, MIT attribution and native suites.

Classic table operations require a quorum. Reconfiguration freezes an old majority and installs recovered state on a new majority. A replica never votes for two successors of the same old configuration. It can learn the successor certified by an old majority despite its different minority vote. A majority-frozen transfer and installed configuration cannot be skipped. Total process loss permits a fresh root, including on reused TCP ports; a fresh incarnation cannot reuse forgotten promises.

## Implemented runtime

- Native IMembershipTable/IGatewayListProvider are wired to automatic hosting, RAM replicas and dynamic configuration resolution. Exclusive fixed-seed/file storage source and configuration were removed.
- Authenticated UDP discovery, directed ranges, fixed memory/byte/row/history/admission bounds, joined shutdown and recipient-incarnation checks are integrated. Same-host observations retain an authenticated loopback address once found. Discovery receive buffers are bounded; observations survive brief startup pauses independently of native failure detection.
- Bootstrap requires a stable lowest candidate and peer agreement. A founding candidate learned from authenticated observations or replies never moves upward during that process lifetime: discovery expiry cannot create an independent root. If the candidate disappears before any cluster forms, remaining processes stay closed until a complete restart. Followers contact the candidate; normal lookup keeps installed/joining peers and a bounded candidate window. Full scans remain periodic and can be requested for graceful departure.
- Three steady-state coordinators can recruit replacements. Graceful departure marks its intent and waits for replacement state before closing. Temporary larger native configurations permit handoff. Surplus retirement requires every participant to acknowledge the installed configuration; an absent or departing old participant cannot make a remaining coordinator retire. Runtime repair completes installation on a responsive replica missed by an earlier quorum response.
- Native RAPID owner repairs cover wildcard advertisement, metadata on rejoin, preservation of deferred join metadata and invalidation of stale deferred work after rejoin. Explicit bootstrap identities separate RAM lifetimes on reused endpoints. Deferred changes already completed by any installed view, including a view learned from a neighbor, are removed before replay. A new native NodeId on a reused endpoint invalidates an old deferred removal. Replay is fenced to the configuration against which it was computed. A completed removal must never become a metadata-free admission in a later view.
